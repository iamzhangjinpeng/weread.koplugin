# Fork 更新待办

插件自带更新器目前仍检查并安装 `finlater/weread.koplugin` 的发行版。
如果确认安装上游发行版，更新器会替换设备上的插件目录，本 fork 的界面改动
也会随之被替换。检查更新本身不会安装更新。

后续需要确定 fork 如何发布，以及如何合并上游更新后再发布。当前只记录这个
问题，更新器保持原样。

此分支基于上游 1.7.0，插件版本标记为 1.6.100，使原插件的手动更新检查能够
识别并安装上游 1.7.0 或更新的正式版。安装更新需要用户确认并重启 KOReader；
更新后此分支的界面改动将从设备上消失，GitHub 分支不受影响。
